# **Ascension Maps - Stronghold Crusader**

![](https://raw.githubusercontent.com/Krarilotus/Ascension/ucp3-ascension/extension-Ascension-Multiplayer/locale/ascension-multiplayer-match.png)

Ascension Maps — это тщательно подобранная коллекция из **114 карт для сражений** в Ascension Multiplayer, включающая соревновательные дуэли, командные битвы, матчи «каждый за себя» и сражения против ИИ.

## **Карты в комплекте**

- **Карты 1 на 1 — 54**: Соревновательные карты для прямых дуэлей между двумя игроками.
- **Командные карты — 39**: Карты для сражений 2 на 2, 2 на 3, 3 на 3, 4 на 4 и 2 на 2 на 2 на 2.
- **Карты «каждый за себя» и по числу игроков — 14**: Открытые форматы для четырёх–восьми игроков.
- **Карты против ИИ — 7**: Сценарии для игроков, сражающихся с противниками под управлением ИИ.

## **Создатели карт**

Карты созданы участниками **Ascension Group**, среди которых **Altaruss'28, CIO61, Lord Hühnerfutter, F2erni8, Krarilotus, Crusader Pilaw, Heroesflorian** и другие.
